One line roasting a smart fridge that refuses to open after midnight, for the [Midnight Fridge Roast](https://make.fun/bounty/u-carbon-forge-midnight-fridge-roast-fc5d44a7) bounty on make.fun.

> My fridge locks at midnight like a bouncer guarding a club — buddy, the only VIP in there is last Tuesday's pizza.

## Run

```sh
node main.ts
```

The program writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), after checking it is a single non-blank line of 1–200 characters.
